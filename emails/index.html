What changed in this pass

  • New login flow: Each login now requires a fresh single-use magic link from /login/. The welcome email's link is one-time-use only. All "save / star / flag / pin this email" copy was removed — saving a single-use link doesn't help.
  • New template added: login-link.html — the recurring magic link sent every time someone requests a login.
  • Brand: "Workiro Accountex Game Plan" → "AutoEvent for Accountex 2026" across all 7 emails.
  • Domain: gameplan.workiro.com → autoevent.io.
  • Privacy URL: /terms-and-policies/accountex-gameplan → /terms-and-policies/autoevent.
  • Anti-spam: subject lines now lead with first name (more personal, less promotional). Welcome email includes a "mark not junk" reminder so future login links land in the inbox.
  • Caption fix: "(No password — same link every time.)" was wrong under the new flow. Updated to "(One-tap login — no password)".
